## 1. 전체 파일 구조
```
seatpick/
 ├─ index.html     ← 프로그램 전부 (화면·디자인·코드가 한 파일)
 ├─ dreamson.png   ← (선택) 꿈송이 이미지. 같은 폴더에 넣으면 자동으로 바뀜. 없으면 기본 캐릭터 표시
 └─ 구조설명.md    ← 이 문서
```
서버·파이어베이스·구글 드라이브를 쓰지 않습니다. GitHub Pages에는 폴더째(index.html) 올리면 됩니다.

## 2. 기능 2가지 (같은 명단 공유)
- **자리 뽑기**: `solve()` / `buildGeo()` — 책상 배치에 학생을 앉힘
- **모둠 뽑기**: `solveGroups()` / `buildGroupGeo()` — 모둠 매트(테이블)에 학생을 내려놓음. 크레인 연출 코드(`runOne`)는 두 기능이 공유

## 2-1. 화면 3개 (index.html 안의 section)
| 화면 | id | 하는 일 |
|---|---|---|
| 준비 | `#setup` | 명단·자리 모양·앞자리·먼저 뽑기·교사 설정 |
| 뽑기 | `#stage` | 캔버스 크레인 연출 |
| 결과 | `#result` | 학생용·교사용 표, 인쇄, 이미지 저장, 엑셀 복사 |

## 3. 데이터 흐름 (교사 ↔ 학생)
이 프로그램은 **교사 한 명이 태블릿/교실 TV에서 돌리는 도구**입니다. 학생 개별 접속·연동 기능은 없습니다.

1. 교사가 엑셀 이름(·성별)을 붙여 넣음 → `S.rosterText` (문자열) → `parseRoster()`가 학생 배열로 변환
2. `startGame()` → `solve()`가 조건(고정석·앞자리·앙숙·남녀 짝·지난번 자리 피하기)을 지키는 배치를 **미리 계산**
3. `begin()` → `runOne()`이 크레인 연출로 한 명씩 공개 (결과는 이미 정해져 있고 연출만 보여줌)
4. 끝나면 `finish()`가 기록을 `S.records`에 저장 → `showResult()`로 결과표 표시
5. 저장 위치는 **이 기기 브라우저의 localStorage** (키: `dudu-seat-v1`). 다른 기기와 자동 공유되지 않음

## 5. 개인정보·오류 위험 지점
- **학생 이름이 브라우저에 저장**됩니다(localStorage). 서버로는 전송되지 않지만, 공용 PC에서 쓴 뒤에는 준비 화면 '모두 지우기'와 '지난 기록 삭제'를 권장합니다. (지난 기록에도 이름이 남습니다)
- **같은 기기·같은 브라우저에서만 기록이 보입니다.** 카카오톡 인앱 브라우저와 크롬은 저장소가 서로 다르므로 한 가지로 통일해서 쓰세요.
- 엑셀(.xlsx) 불러오기는 외부 라이브러리(jsDelivr)를 인터넷으로 불러옵니다. 오프라인이면 실패하니 **엑셀에서 복사해 붙여 넣기**를 쓰세요.
- 학생 수 > 자리 수이면 시작되지 않습니다(자리 모양에서 '학생 수에 맞추기').
- 앙숙·고정석 조건이 서로 충돌하면 가장 가까운 배치로 진행하고 안내 문구가 뜹니다.
- 동명이인은 자동으로 ②, ③을 붙입니다.
- 인쇄는 PC 크롬에서 가장 안정적입니다(카카오톡 인앱 브라우저는 인쇄 미지원 → '이미지 저장' 사용).
- 연출은 결과를 보여주는 효과이며, 실제 자리는 조건을 지키도록 미리 정해진다는 점을 학생에게 숨기고 싶지 않다면 '프로그램 정보'에 적힌 설명을 그대로 안내하세요.

- 모둠 기능도 같은 localStorage(`dudu-seat-v1`)에 저장됩니다. 지난 기록에 자리·모둠이 함께 쌓이며, '지난 조합 피하기'는 가장 최근 **모둠** 기록과만 비교합니다.
- 모둠 인원이 학생 수로 나누어떨어지지 않으면 모둠 간 인원 차이가 최대 1명이 되도록 나눕니다(예: 25명·6모둠 → 5명 1개, 4명 5개).


## 추가 (반별·교실 배치·폰트·인쇄)
- 반별 명렬: `CKEYS`에 적힌 항목은 반마다 따로 저장됩니다. `S.classes`에 반 목록, `switchClass()`로 전환, `save()`가 현재 반을 동기화. 저장 위치는 브라우저 localStorage(`dudu-seat-v1`)이므로 기기를 바꾸면 보이지 않습니다.
- 교실 모양: `S.blocked`(책상 없는 칸 번호), `preset()`(전부 책상/ㄷ자/가운데 통로/맨 뒷줄 비우기). 미리보기에서 칸을 눌러 수정.
- 엑셀 불러오기: 여러 시트를 반으로 변환(`loadFile`). xlsx 라이브러리는 인터넷 필요.
- 인쇄/PDF/이미지: `#printArea`+`@media print`, `showPdf()`는 jsPDF(CDN, 인터넷 필요), `sheetCanvas`/`groupCanvas`로 PNG.
- 폰트: Noto Serif KR(제목)+Noto Sans KR(본문), 구글폰트. 폰트 바꿀 곳은 `FONT` 상수와 `<link>`.
- 마스코트: `kkumsong.png`(없으면 SVG 대체). 
- 개인정보 주의: 학생 이름은 서버로 가지 않고 기기 안에만 저장됩니다. 공용 PC에서는 사용 후 기록 삭제.
